# 📸 Quick Screenshot Guide for Exam Submission

## How to Capture Screenshots of Your Project

### For Windows:
1. Open website: https://resultpro.preview.emergentagent.com
2. Press `Win + Shift + S` (Snipping Tool)
3. Select area to capture
4. Screenshot saves to clipboard
5. Paste into Word/PowerPoint or save as image

### For Mac:
1. Open website: https://resultpro.preview.emergentagent.com
2. Press `Cmd + Shift + 4`
3. Click and drag to select area
4. Screenshot saves to Desktop

### For Chrome (Any OS):
1. Open website
2. Press `F12` (Developer Tools)
3. Press `Ctrl + Shift + P` (Windows) or `Cmd + Shift + P` (Mac)
4. Type "screenshot"
5. Select "Capture full size screenshot"

## 🎥 Optional: Record Video Demo

### Using Windows Game Bar:
1. Press `Win + G`
2. Click record button (red circle)
3. Navigate through application
4. Stop recording (square button)
5. Video saves to Videos > Captures folder

### Using OBS Studio (Free):
1. Download OBS Studio
2. Add "Display Capture" source
3. Click "Start Recording"
4. Show application features
5. Click "Stop Recording"

### Using Chrome Extension:
1. Install "Loom" or "Screencastify"
2. Click extension icon
3. Choose "Record tab"
4. Navigate through application
5. Stop and download video

## 💡 Pro Tips for Screenshots

1. **High Quality**: Take screenshots in full HD (1920x1080)
2. **Clean Browser**: Hide bookmarks bar, close other tabs
3. **Zoom Level**: Keep browser at 100% zoom
4. **Highlight**: Use annotation tools to highlight key features
5. **Consistency**: Use same window size for all screenshots
6. **Captions**: Add clear captions explaining each screenshot
